# Campus Customs front end

React + Vite + TypeScript storefront for Campus Customs (Yale Bulldog Blue).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # type-check + production build
npm run lint
```

Pages (react-router-dom): Home `/`, Products `/products`, About Us `/about`, Log in `/login`, Create account `/signup`.
Product data, sign-up/login and the chatbot connect to the FastAPI backend in later steps.
